# Drizzle Migrations

This directory contains generated SQL migrations for the IntentGuard PostgreSQL schema.

## Architectural Decisions

Migrations are generated by Drizzle Kit from the schema entry point in [../cli/db/schema/index.ts](file:///C:/Hackathons/Zerion%20CLI/cli/db/schema/index.ts).

The generated SQL should be reviewed before applying it to any database because it creates financial automation and execution audit tables.

## Files

To find the initial generated migration visit [0000_slimy_xorn.sql](file:///C:/Hackathons/Zerion%20CLI/drizzle/0000_slimy_xorn.sql).

The migration metadata can be found in [meta/_journal.json](file:///C:/Hackathons/Zerion%20CLI/drizzle/meta/_journal.json).

## Tradeoffs

Generated migrations are committed so the database shape is reproducible. The tradeoff is that schema changes must be made in Drizzle source first, then regenerated instead of editing migration SQL by hand.
